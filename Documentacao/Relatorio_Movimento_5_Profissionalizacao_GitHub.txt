==================================================
OBJETIVO DO MOVIMENTO 5
==================================================

Transformar a N.E.M.O. em um projeto de software organizado,
utilizando ferramentas profissionais de desenvolvimento.

A partir deste movimento, a N.E.M.O. deixa de ser apenas uma
estrutura de conhecimento e passa a ser tratada como um sistema
em evolução contínua.


==================================================
MUDANÇA DE METODOLOGIA
==================================================

Antes:

- arquivos locais;
- desenvolvimento manual;
- controle individual das alterações.

Depois:

- controle de versão;
- histórico de mudanças;
- organização profissional;
- documentação técnica;
- evolução segura.


==================================================
IMPLEMENTAÇÃO DO GITHUB
==================================================

O GitHub será utilizado como plataforma de gerenciamento do projeto.

Objetivos:

- armazenar código;
- controlar versões;
- registrar evoluções;
- documentar melhorias;
- criar histórico da N.E.M.O.
